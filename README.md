# FaceitLike Bot — pickup-бот для Discord (5x5, Standoff 2)

Бот на discord.py, который реализует основную логику faceit-подобных
pickup-ботов: очередь, автобалансировка команд по рейтингу (ELO),
автосоздание голосовых каналов на матч и вето карт кнопками.

**Важно:** у Standoff 2 нет публичного API/RCON/логов сервера, поэтому
бот не может сам определить победителя матча — результат вводит
капитан или админ командой `/matchscore` после игры.

## Функции

- `/register` — регистрация в системе рейтинга (старт: 1000 ELO)
- `/profile [user]` — профиль: ELO, W/L, winrate
- `/leaderboard` — топ-10 сервера по рейтингу
- `/queue` — встать в очередь (5x5, всего 10 человек)
- `/leavequeue` — выйти из очереди
- `/queuestatus` — кто сейчас в очереди
- Когда очередь набирается (10/10), бот автоматически:
  - разбивает игроков на две максимально равные по силе команды
    (змейка-драфт по ELO)
  - создаёт категорию `МАТЧ #ID` с текстовым и двумя голосовыми каналами
  - переносит игроков, которые уже сидят в войсе, в их канал команды
  - назначает капитанами игроков с наивысшим ELO в каждой команде
  - запускает вето карт кнопками (капитаны по очереди банят карты,
    пока не останется одна)
- `/matchscore <id> <A/B>` — сообщить победителя, пересчитывает ELO
  всем 10 игрокам по формуле Эло (K=32) и удаляет каналы матча
- `/cancelmatch <id>` — отменить матч без изменения рейтинга (только админ)

## Установка (базовая часть, одинаковая везде)

1. Создай приложение и бота на https://discord.com/developers/applications
2. В разделе **Bot** включи привилегированные интенты:
   `SERVER MEMBERS INTENT`, `MESSAGE CONTENT INTENT`
3. Скопируй токен бота (Bot → Reset Token) — он понадобится дальше.
4. Пригласи бота на сервер (OAuth2 → URL Generator → scope `bot` +
   `applications.commands`) с правами:
   - Управление каналами (Manage Channels)
   - Перемещение участников (Move Members)
   - Отправка сообщений, встраивания (Embed Links)
   Либо просто выдай `Administrator`, если сервер тестовый.

## Как запустить и чтобы бот работал сам, без твоего участия

Discord-боты — это обычный процесс, который должен **постоянно
где-то работать**. "Постоянно" = либо телефон/комп не выключается
никогда, либо код лежит на облачном сервере. Второй вариант — то,
что тебе на самом деле нужно, если хочешь "запустил и забыл".

### Вариант 1 (рекомендуется): облачный хостинг — управляется с телефона, работает 24/7 сам по себе

Не важно, Android у тебя или iOS — весь процесс происходит в
браузере на сайте хостинга, телефон после этого можно выключить,
бот продолжит работать на сервере.

Примерные шаги (на примере Railway, есть бесплатный лимит):
1. Загрузи папку `facebot` в репозиторий на GitHub (можно прямо с
   телефона через приложение GitHub или сайт github.com — "Add file
   → Upload files").
2. Зайди на railway.app, "New Project → Deploy from GitHub repo",
   выбери свой репозиторий.
3. В Variables добавь `DISCORD_TOKEN` = твой токен.
4. Railway сам поставит зависимости из `requirements.txt` и запустит
   `python bot.py`. Готово — бот работает постоянно.

Альтернативы Railway: Render.com, обычный VPS (Timeweb, Selectel,
Timeweb Cloud, Reg.ru и т.п. — от ~150-300₽/мес), на VPS дополнительно
нужно один раз настроть автозапуск (`systemd` unit или `pm2`), чтобы
бот поднимался сам после перезагрузки сервера.

### Вариант 2: запустить прямо с телефона

- **Android:** есть приложение **Termux** — в нём можно поставить
  Python и запустить бота (`pkg install python`, `pip install -r
  requirements.txt`, `python bot.py`). Работает, но ненадёжно для
  "24/7 без твоего участия": Android будет "убивать" процесс в фоне
  для экономии батареи, если явно не отключить оптимизацию батареи
  для Termux и не держать телефон подключённым к сети/питанию.
  Подходит для теста, не для постоянной работы.
- **iOS:** запустить постоянно работающий python-процесс на самом
  iPhone нельзя — Apple не разрешает такое приложениям (нет аналога
  Termux с полноценным фоновым процессом). С iOS/Android можно только
  **управлять** сервером — например, через приложение-SSH-клиент
  (Termius и т.п.) подключиться к VPS и там запустить бота, либо
  просто зайти в браузере на Railway/Render как в варианте 1.

**Итог:** если нужно "работает само, без моего участия" — это
Вариант 1 (облако), с телефона любой ОС им можно полностью управлять
через браузер, сам телефон при этом не должен быть включён.

Slash-команды синхронизируются автоматически при старте
(может занять до часа для глобальной синхронизации в Discord —
если нужно мгновенно, синхронизируй команды для конкретного сервера
в `setup_hook`, заменив `self.tree.sync()` на sync с `guild=`).

## Настройки

Все параметры — формат матча, стартовый ELO, коэффициент K, пул карт —
находятся в `config.py`.

## Структура проекта

```
facebot/
├── bot.py                 # точка входа
├── config.py               # настройки
├── database.py             # SQLite: игроки, очередь, матчи
├── requirements.txt
├── .env.example
└── cogs/
    ├── registration.py     # /register /profile /leaderboard
    ├── queue_cog.py         # /queue /leavequeue /queuestatus
    └── match_cog.py         # балансировка, вето, /matchscore /cancelmatch
```

## Возможные доработки

- Ручной выбор капитанов вместо автоназначения по ELO
- Best-of-3 вето (пик/бан вместо только банов)
- Привязка Steam ID и подтягивание статистики матча с игрового сервера
- Роли/пермишены очереди (например, только для верифицированных)
- Таймаут очереди — автоматический сброс, если кто-то не готов
